# Exact decomposition of E16 capacity computations

The original definitions of `candidateBlock`, `capacityBlock`, `enumerateCompact`, and every filter remain unchanged. The modules described here prove equality-preserving decompositions of those definitions, so they can be used to compute a large finite proof in smaller Lean processes.

`OriginalCapacityBlockDecomposition.lean` unfolds one recursion layer of `enumerateCompact`. For total profile length `t+2` and largest quotient `u`, it proves that `capacityBlock e (t+2) u` is exactly the concatenation over every `v` in `List.range' 2 (u-1)` of `capacitySubBlock e t u v`. The high-quotient budget after choosing `u` is exactly `e-(t+2)-cost u`. Every original compatibility, partial-capacity, final, Bonferroni, half-Bonferroni, and aggregate-capacity filter is retained. The proof uses distribution of list `filter` and `map` over `flatMap`.

`OriginalCapacityBlockShortcuts.lean` proves that a subblock is empty if the existing predicate `compatible e u v` is false. Every list in that subblock would start with `u,v`, and therefore fails the already present outer compatibility filter. This is an exact empty-list equality, not an additional mathematical restriction.

`OriginalCapacityNestedDecomposition.lean` similarly fixes a third quotient. For total length `t+3`, the remaining budget after `u,v` is exactly `e-(t+3)-cost u-cost v`. It proves that `capacitySubBlock e (t+1) u v` is the concatenation of all third-quotient branches over `List.range' 2 (v-1)`. An analogous exact empty-branch lemma applies when the existing compatibility predicate for `v,w` is false. No quotient value or empty branch is omitted from the concatenation identities.

All three modules have actual Lean `-j1 -t0` exit-zero checks with no warnings and only the standard three axioms. The shortcut and third-quotient modules were compiled through the shared four-slot `e16-core-v1` process pool; measured peak RSS was respectively 3,365,188 and 3,368,500 KiB.

The motivation was a resource termination, exit 137 with an empty Lean log, of the original one-piece `K8U10` calculation. Its earlier failed attempt was retained in the block ledger. The replacement six-piece calculation and its exact original-block assembly all subsequently completed with actual exit code zero. It certifies the same `block_checked_16_8_10` statement. The largest measured pilot piece used 11,858,532 KiB RSS, so later larger blocks use the third-quotient decomposition and remain in the shared pool. The failure was not counted as a proof, and no mathematical condition was changed in response to it.

These decomposition lemmas do not themselves establish the complete E16 literal profile table. Full table coverage still requires all 200 original block equalities, the already checked complete block index, and the final concatenation theorem. The builder's completion ledger is authoritative for that separate milestone.

## Arbitrary-depth continuation

`OriginalCapacityPrefixDecomposition.lean` extends the same equality argument to any fixed prefix. `prefixPipeline` is a right fold of the original prepend-and-filter operation; `finishPipeline` applies the original complete and aggregate tests exactly once at the end. The theorem `prefixBlock_succ_eq_flatMap` replaces one remaining recursion layer by all next quotients in the original range, with the original cost guard and budget subtraction. The total `count` passed to every partial test remains fixed. Exact guard-preserving equalities connect the original one-, two-, and three-quotient block interfaces to this representation.

The module was actually checked with `-j1 -t0` through the same shared pool, exit zero, no warnings, and only the standard three axioms. Its measured peak RSS was 3,377,556 KiB. This allows a computational leaf to be subdivided repeatedly if its measured memory exceeds the desired budget; it does not add any mathematical pruning condition or replace a failed proof by an assumption.

`OriginalCapacityPrefixShortcuts.lean` proves two further exact empty-list equalities. Every intermediate candidate returned by `prefixPipeline` contains the fixed prefix as a sublist. If that prefix's weight already exceeds the original pair-capacity Bonferroni bound, or the original aggregate-capacity bound, the original all-sublist final test must reject every completion. Hence the corresponding `prefixBlock` is empty without evaluating its remaining tail enumeration. These proofs require no active-family, failure, minimality, or `count=length` assumption: they are consequences of the existing executable final filters. This fifth module passed `-j1 -t0` in the shared pool with no warnings, standard axioms only, and peak RSS 3,372,036 KiB.

`OriginalCapacityPrefixTests.lean` proves the convenient stronger Boolean form: if either existing `bonferroniTests` or `aggregateTests` rejects the entire fixed prefix, the corresponding `prefixBlock` is exactly empty. Both tests are hereditary under positional sublists. For the second, half-layer conjunct of `aggregateTests`, the proof uses the genuine inequality `pref.length ≤ full.length`; passing the full test therefore implies passing the weaker prefix-length test. It never substitutes the unrelated enumeration parameter `count` for either length. This sixth module passed the same pooled trust-zero check with no warnings, standard axioms only, and peak RSS 3,370,680 KiB.

## Using the proved full output length

`OriginalCapacityCountedPrefix.lean` proves by induction that every list emitted by `enumerateCompact` has the requested remaining length, and that `prefixPipeline` adds exactly the prefix length. Thus every member of a `prefixBlock` has length `pref.length + remaining`. The final shortcut explicitly assumes `pref.length + remaining = count` before using `count` in the half-capacity check. Under that premise, every full candidate passing the original aggregate test also passes the same test restricted to prefix sublists with the genuine full output length. If this `countedAggregateTests` is false, the original block is exactly empty. The actual compile exited zero with `-j1 -t0`, no warnings, standard axioms only, and peak RSS 3,379,908 KiB.
